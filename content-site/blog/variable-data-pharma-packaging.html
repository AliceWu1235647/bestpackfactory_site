Code format

GS1 DataMatrix ECC200 is recommended for one-item-one-code pharma and medical aesthetic packaging. Module size is commonly 0.30–0.50 mm.

Verification

ISO/IEC 15415 Grade A target should be verified at print approval. After folding and gluing, Grade B minimum is a practical production target.

Anti-abrasion

Keep the code away from glue seams, crease lines and carton edges. Use layout clearance and camera inspection to reduce transport scuff risk.

GS1 DataMatrix verification method and real grading data

Method: Verify both encoded data and print quality on the final printed carton. Record the code content, X-dimension, quiet zone, location, verifier model and calibration status, plus the complete grade notation.

  • The official GS1 DataMatrix Guideline states that quality covers both correct GS1 data and symbol print quality. Its ISO/IEC 15415 scale runs from numeric grade 4 (best) to 0 (worst), corresponding to letter grades A through F.
  • ISO/IEC 15415:2024 defines measurement and grading methods for two-dimensional barcode symbols.

Evidence limit: A reported grade is meaningful only with the aperture, illumination and angle. Grade A or B figures on this site are project targets, not claims about an untested production lot.
