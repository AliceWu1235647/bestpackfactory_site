Custom Packaging Artwork File Checklist: Prepress Essentials for Buyers

Published August 27, 2026 · Buyer guide · By BestPackFactory

Quick answer

Submit artwork in the supplier required format with correct bleed, converted fonts, CMYK or spot colors, and sufficient resolution (typically 300 dpi for print). Include the approved dieline layer and label every file clearly. Missing bleed or low resolution are the most common rejection reasons.

Set up the file once, correctly

Use the supplier dieline as the base layer, extend artwork to the bleed, and keep critical content in the safe zone. Correct setup prevents most prepress rejections.

Fonts and colors are the classic traps

Convert fonts to outlines or embed them; convert images to CMYK or define spot colors as approved. An RGB file can print with noticeably different color.

Resolution decides sharpness

Print requires roughly 300 dpi at final size. A logo pulled from a website will look soft on a box. Check effective resolution of every placed image.

Label and communicate

Name files with SKU and version, and confirm which file matches which dieline. A clear file structure avoids mixing versions across the run.

Buyer checklist

  1. Use the supplier dieline as base
  2. Extend bleed correctly
  3. Outline or embed fonts
  4. Convert to CMYK or spots
  5. Check 300 dpi at final size

Frequently asked questions

Why was my artwork rejected?

Common reasons: missing bleed, low resolution, RGB color or live fonts. Check the prepress list before resubmitting.

JPEG or PDF for print?

Use print-ready PDF or the supplier-required vector format; JPEG loses quality and control.

What resolution do I need?

About 300 dpi at final printed size for crisp images and logos.

What the Spec Means for Buyers

Artwork files decide print quality before the press runs. Standard requirements: AI, PDF, PSD, EPS or high-resolution files; vector logo; outlined fonts; 3 mm bleed. Color is matched CMYK + Pantone against the approved digital proof at ΔE ≤ 3.0; for offset printing, registration holds ±0.15 mm (cartons) and die-cut tolerance ±1.5 mm. Variable codes (GS1 DataMatrix) need a quiet zone of ≥ 4X module width. MOQ is 500 PCS per size and artwork.

Frequently Asked Questions

What file formats are accepted?

AI, PDF, PSD, EPS or high-resolution files with a vector logo, outlined fonts and 3 mm bleed.

Why is 3 mm bleed required?

Bleed covers die-cutting tolerance (±1.5 mm) so printed color runs edge-to-edge without white gaps.
